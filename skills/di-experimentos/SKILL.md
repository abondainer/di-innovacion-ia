# Prototipos y experimentos · Distilled Innovation

## 1. Mapa de supuestos (la IA como socio de VC)
Identifica 6 supuestos críticos clasificados en **deseabilidad** (¿lo quieren?), **viabilidad** (¿genera valor al negocio?) y **factibilidad** (¿podemos?). Para cada uno: nombre (≤8 palabras), qué pasa si falla, certeza (Evidencia / Supuesto / Desconocido).
**Supuesto asesino** = máxima criticidad + mínima evidencia (casi siempre en deseabilidad: ¿alguien pagaría?).

## 2. Prototipo más simple
| Tipo | Prueba | Herramientas IA |
|---|---|---|
| Storyboard | Si la experiencia tiene sentido | Chat + generador de imágenes |
| Landing page | Si hay interés real (registros, preventas) | Lovable, Gamma, Framer AI, Claude artifacts |
| Mockup de pantallas | Si el flujo es claro | v0, Lovable, Figma AI |
| Simulación con IA | Si el servicio aporta valor en conversación | Proyecto de Claude, GPT, Gem |
| Mago de Oz | Si lo usan cuando parece automático | Formulario + persona detrás |
Escribe el prompt listo para la herramienta. Sin testimonios, cifras ni logos inventados.

## 3. Tres experimentos
De menor a mayor esfuerzo. Cada uno: nombre · acción exacta · con quién (perfil concreto) · tiempo · **criterio de éxito** · **criterio de fracaso**. El 1 se ejecuta esta semana sin presupuesto. Mide comportamiento, no opinión. Sin criterio de fracaso no es un experimento: es una actividad.

## 4. Test Card
```
TEST CARD
Creemos que…
Para verificarlo, vamos a…
Y mediremos…
Estamos en lo correcto si… (número + plazo)
Fracaso si…
Costo: bajo/medio/alto · Tiempo: · Confianza de la evidencia: bajo/medio/alto
```
Revisa: ¿un solo supuesto?, ¿el experimento lo prueba?, ¿mide comportamiento?, ¿umbral con número y plazo?

## 5. Learning Card (después de la prueba)
```
LEARNING CARD
Creíamos que…
Observamos…
De esto aprendimos que…
Por lo tanto, vamos a… (seguir · ajustar · detener)
```

## Reglas
- No inventes resultados. Separa datos de interpretación. Umbrales provisionales: los aprueba el equipo.
- Separa HECHOS, INFERENCIAS e HIPÓTESIS.
